# FreeCell Solver

Project game FreeCell viet bang Python, co giao dien `tkinter` va nhieu thuat toan giai nhu `BFS`, `DFS`, `UCS`, `A*`, `Expert Solver`.

## Cau truc thu muc

```text
AI-Project1-FreeCell-Solver/
|-- experiments/
|-- game/
|-- gui/
|-- solvers/
|-- tests/
|-- main.py
|-- README.md
`-- requirements.txt
```

## Cach chay

Yeu cau:
- Python 3.10 tro len
- Co san `tkinter`

Cai thu vien:

```bash
pip install -r requirements.txt
```

Chay chuong trinh:

```bash
python main.py
```
